# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately:

1. **Do not open a public GitHub issue.**
2. Report via email to **security@hummbl.io** or open a private Security Advisory on GitHub.
3. Include: description of the vulnerability, steps to reproduce, expected vs. observed behavior, and potential impact.

You can expect an initial response within 48 hours. If the vulnerability is confirmed, a fix will be prioritized and coordinated under responsible disclosure guidelines.

## Scope

This policy applies to all code, documentation, and infrastructure within this repository under the HUMMBL standard.
